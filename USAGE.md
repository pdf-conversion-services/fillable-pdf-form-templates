# Usage and quality guide

Choose a template, save a copy, enter the contact details, select a project purpose and describe the information you need to collect. The form uses text fields, a dropdown and a checkbox. It has no automatic submission, calculation or digital signature.

## Adaptation checklist

1. Define the minimum information needed to process the request.
2. Use clear field labels and add choices only when the list is stable.
3. Decide how completed copies will be returned and stored.
4. Use fictional data during testing.
5. Test tab navigation, long answers, save/reopen and printing in the intended reader.

The checkbox records a review acknowledgement only. It is not a consent framework or an electronic signature. Dates and email addresses are plain text and have no validation rules. For more complex forms, document the calculation and validation requirements separately.

## Screenshot provenance

The `*-blank.png` and `*-filled.png` files are direct 110 dpi Poppler renders of the PDFs generated by the included script. Filled PDFs exist only temporarily during validation. Published downloadable templates remain blank and interactive.
